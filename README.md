# AI Tech Solutions - Job Application Form

A simple and interactive job application form built using HTML, CSS, and JavaScript.

## Features

- Company introduction
- Multi-step application form
- Personal and education information
- Skills and languages selection
- Experience and projects section
- CV and document upload
- Form validation
- Progress bar
- Success confirmation page
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
